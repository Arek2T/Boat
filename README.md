# Ship

Unity 6000.5.11f1

## Controls

- W / S - Open / close sails
- A / D - Rotate sails
- Left / Right Arrow - Move Rudder
- Right Mouse Button + Mouse - Orbit camera
- Mouse Wheel - Zoom
- 1 - Toggle other sail renderers
- 2 - Toggle wind debug HUD
- 3 - End sequence

## Technical Notes

- Unity UI Toolkit
- New Input System
- Custom boat movement without Rigidbody or collisions
- Wind and apparent wind simulation
- Water drag
- Procedural sail deformation
- IL2CPP
